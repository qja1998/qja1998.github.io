# 문제
[보호소에서 중성화한 동물](https://school.programmers.co.kr/learn/courses/30/lessons/59045)

# 풀이

## 코드
```sql
SELECT ins.animal_id, ins.animal_type, ins.name
FROM animal_ins AS ins
JOIN
animal_outs AS outs
ON ins.animal_id = outs.animal_id
WHERE ins.sex_upon_intake REGEXP 'Intact' 
    AND outs.sex_upon_outcome REGEXP 'Spayed|Neutered'
ORDER BY ins.animal_id```

## 설명
이 문제는 SQL을 활용한 데이터 조회 문제다.

### 접근 방법
문제의 요구사항을 분석하여 적절한 SQL 쿼리를 작성했다.

### 주요 포인트
- 필요한 테이블 JOIN
- WHERE 조건절을 통한 데이터 필터링
- ORDER BY를 통한 정렬

### 시간 복잡도
데이터베이스 인덱스와 쿼리 최적화에 따라 성능이 결정된다.
