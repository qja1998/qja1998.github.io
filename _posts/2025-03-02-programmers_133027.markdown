# 문제
[주문량이 많은 아이스크림들 조회하기](https://school.programmers.co.kr/learn/courses/30/lessons/133027)

# 풀이

## 코드
```sql
SELECT J.FLAVOR
FROM FIRST_HALF F
    INNER JOIN (SELECT FLAVOR, SUM(TOTAL_ORDER) AS JULY_TOTAL_ORDER
                FROM JULY
                GROUP BY FLAVOR) J
        ON F.FLAVOR = J.FLAVOR
ORDER BY TOTAL_ORDER + JULY_TOTAL_ORDER DESC
LIMIT 3;
```

## 설명
이 문제는 SQL을 활용한 데이터 조회 문제다.

### 접근 방법
문제의 요구사항을 분석하여 적절한 SQL 쿼리를 작성했다.

### 주요 포인트
- 필요한 테이블 JOIN
- WHERE 조건절을 통한 데이터 필터링
- ORDER BY를 통한 정렬

### 시간 복잡도
데이터베이스 인덱스와 쿼리 최적화에 따라 성능이 결정된다.
