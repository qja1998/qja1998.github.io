# 문제
[연도별 대장균 크기의 편차 구하기 ](https://school.programmers.co.kr/learn/courses/30/lessons/299310)

# 풀이

## 코드
```sql
SELECT year(differentiation_date) AS YEAR,
(
    SELECT MAX(size_of_colony) FROM ecoli_data
    WHERE year(differentiation_date) = year
) - size_of_colony AS YEAR_DEV,
ID
FROM ECOLI_DATA
ORDER BY YEAR, YEAR_DEV
```

## 설명
이 문제는 SQL을 활용한 데이터 조회 문제다.

### 접근 방법
문제의 요구사항을 분석하여 적절한 SQL 쿼리를 작성했다.

### 주요 포인트
- 필요한 테이블 JOIN
- WHERE 조건절을 통한 데이터 필터링
- ORDER BY를 통한 정렬

### 시간 복잡도
데이터베이스 인덱스와 쿼리 최적화에 따라 성능이 결정된다.
