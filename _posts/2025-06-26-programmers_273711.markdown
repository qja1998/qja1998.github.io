# 문제
[업그레이드 된 아이템 구하기](https://school.programmers.co.kr/learn/courses/30/lessons/273711)

# 풀이

## 코드
```sql
WITH rare_item AS (
    SELECT it.item_id
    FROM item_info AS ii
        JOIN
        item_tree AS it
        ON ii.item_id = it.parent_item_id
    WHERE rarity = "RARE"
)

# SELECT *
# FROM rare_item

SELECT ii.item_id, ii.item_name, ii.rarity
FROM rare_item AS ri
    JOIN
    item_info AS ii
    ON ri.item_id = ii.item_id
ORDER BY ii.item_id DESC
```

## 설명
이 문제는 SQL을 활용한 데이터 조회 문제다.

### 접근 방법
문제의 요구사항을 분석하여 적절한 SQL 쿼리를 작성했다.

### 주요 포인트
- 필요한 테이블 JOIN
- WHERE 조건절을 통한 데이터 필터링
- ORDER BY를 통한 정렬

### 시간 복잡도
데이터베이스 인덱스와 쿼리 최적화에 따라 성능이 결정된다.
